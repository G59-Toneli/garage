Garage está fora do ar

O servidor web está de pé e o serviço por trás dele não está respondendo. Nada foi consultado e nada está sendo escondido — não há o que mostrar.

A causa mais provável não é uma queda: o serviço se recusa a subir contra um banco que não é o artefato deste commit. O corpus_hash gravado no banco, ou o de algum registro de showcase committado, diverge do que este código descreve. Essa recusa é o comportamento correto: servir números sobre material que este artefato não contém seria pior do que não servir nada, porque pareceria igualmente confiável.

Operador: docker compose logs serve nomeia os dois hashes. O conserto é python -m garage ingest e, se um registro de showcase divergir, reconstruí-lo ou removê-lo. Veja docs/deploy.md.
